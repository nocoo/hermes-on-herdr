## 证据等级

| 标记 | 含义 | 可以证明什么 |
|---|---|---|
| V | 实际观察／执行 | 版本、源码摘要、文档检查，以及明确注明范围的本地离线测试 |
| S | 固定版本源码 | 指定 SHA 的分支、字段、调用关系；不等于真实环境集成测试 |
| D | 官方文档公开说明 | 抓取时的用户契约；在线文档可能领先本机代码 |
| A | 类似实现 | 借鉴设计与事故教训；不继承对方的运行验证结论 |
| P | 本项目设计提案 | 待实现接口、超时、状态机、目录、manifest、服务模板 |
| X | 待 spike 验证 | PTY/信号、handoff、真实 token、OS 服务等尚未运行的假设 |

Hxx/Mxx 是 S 证据索引，Pxx 是 A 证据索引，Oxx 是 D 证据索引。正文标注“拟定”“要求”“默认值”时是本项目规范 P，不是上游已经提供的功能。未写“已执行”的命令均不算本轮测试结果。

源码和在线文档冲突时，记录差异并按目标 SHA 设计；不能用“最新版应该如此”抹掉差异。本机版本号匹配 tag 也不等于二进制与源码的可复现构建证明。

## 统一术语和约束

| 术语 | 本文含义 |
|---|---|
| Herdr session | 一个 Herdr Server/API socket 管理的 workspace 集合；不是 Hermes 对话 session |
| owner session | 插件配置中唯一允许拥有 `herdr-control` Gateway 的 Herdr session |
| Profile | Hermes 的 HERMES_HOME 命名空间；不是隔离容器 |
| controller | hook/action/timer 调用的一次性短进程，执行 ensure 或持久化动作 |
| supervisor | 真实 plugin pane 的前台主进程，持有 lifetime lock，监督一个 Gateway child |
| adopt | 接受存活 supervisor/pane 为原实例，修复插件自己的账本；不回填 Herdr 私有 plugin_panes 表 |
| replace | 安全回收旧空壳／孤儿后，经 Herdr API 创建新的 argv pane |
| ready | 活身份及 runtime/期望平台状态满足02的有限定义；不等于业务 E2E 成功 |
| pause | 持久禁止自动启动；Stop 动作也写此意图，只有显式 Resume 清除 |
| fuse | 有界重试后或配置／身份冲突时熔断；自动 hook 不解锁熔断 |

所有终止与清理都限定到已验证身份。所有启动都需要既有且已配置完成的专用 Profile。首轮离线记录保存在12；13记录本机插件禁用安装和已有 cherry 的只读基线，正式切换及停服验证仍待确认。
