## 9.2 Herdr

<a id="h01"></a>
### H01 · Manifest、ID、入口目录

[manifest.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/app/api/plugins/manifest.rs#L11)，`RawPluginManifest`、`load_plugin_manifest`（118–150）、`validate_min_herdr_version`（227–255）、ID validators（590–607）。目录默认读取 `herdr-plugin.toml`；`id/name/version` 必需，`min_herdr_version` 虽以 Option 反序列化，校验仍要求提供。plugin ID ≤120 字符，可含 ASCII 字母、数字、`:`、`.`、`_`、`-`；pane/action 本地 ID 不允许 `.`。repo 名不由 manifest parser 校验，`<thing>-herdr` 是生态惯例。

<a id="h02"></a>
### H02 · 插件配置、状态、session socket

[plugin_paths.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/plugin_paths.rs#L5)，`managed_checkout_path`、`plugin_config_dir`、`plugin_state_dir`；[config/io.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/config/io.rs#L30)，`config_dir/state_dir`；[session.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/session.rs#L157)，session 路径选择。

配置位于 `<config>/plugins/config/<encoded-id>`，状态位于 `<state>/plugins/<encoded-id>`，并不自动按 session 分区；GitHub checkout 位于 `<config>/plugins/github/<managed-id>`。默认 socket 为 `<config>/herdr.sock`，named session 在 `<config>/sessions/<name>/herdr.sock`。显式 `--session` 优先于继承的 `HERDR_SOCKET_PATH`；XDG 配置可改变根路径。

<a id="h03"></a>
### H03 · Startup/action/event 只是异步命令

[runtime.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/app/api/plugins/runtime.rs#L16)，`start_plugin_command`（16–180）、`run_plugin_startup_hooks`（182–217）、`run_plugin_event_hooks`（219–276）。每个 entry 单独异步 spawn；排序不能消除并发。stdout/stderr 通过管道读取，`child.wait()` 后还 join reader；孙进程继承管道会阻止日志完成。并发上限32、每流输出64 KiB、最近日志200条；没有重启循环或命令执行超时。hook 环境中的 pane ID 来自调用时焦点 context（64–71）。

<a id="h04"></a>
### H04 · 真正的 argv pane 和真实环境

[plugins/panes.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/app/api/plugins/panes.rs#L174)，plugin tab 创建（174–234）、env 注入（236–268）、ownership 入表及保存（272–306）；[pane.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/pane.rs#L138)，`apply_pane_launch_env`（138–160）；同文件 [spawn_argv_command](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/pane.rs#L2026)。真实 workspace/tab/pane IDs 在 extra env 后覆盖；argv 直接交给命令构造器，非 shell 文本注入。

[plugins/mod.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/app/api/plugins/mod.rs#L461) 只把 `command[0]` 的相对路径转为 plugin-root 路径，后续 argv 不替换。`["python3", "./src/main.py"]` 仍依赖 cwd，故拟用相对可执行 launcher，并显式指定 plugin pane cwd。

### H06 · Pane 退出和 shell fallback

[workspace/tab.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/workspace/tab.rs#L92)，argv construction（92–174）；[app/api.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/app/api.rs#L497)，`runtime_exit_action`：有 respawn flag 才回到 shell，否则 ClosePane。普通 argv plugin pane 没有自动 respawn supervisor 的能力。

同文件 [PaneDied 处理](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/app/api.rs#L219)：shell respawn 成功会提前 return；普通退出到265–275才发 `pane.exited`。不能把退出事件当成可靠的周期监视器。

<a id="h07"></a>
### H07 · Session snapshot 与 debounce

[persist/snapshot.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/persist/snapshot.rs#L16)，snapshot structures 与构造（16–109）：记录布局、cwd、label、launch_argv，没有 plugin_panes 表。[app/mod.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/app/mod.rs#L43)，保存 debounce 常量5秒；[app/session.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/app/session.rs#L14)，`schedule_session_save` 重新推迟 deadline。风险窗口为最后一次变动后约5秒，持续变更时可更长，不能假定5秒后必然已经持久化。

<a id="h08"></a>
### H08 · 冷恢复不重放 launch argv

[persist/restore.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/persist/restore.rs#L493)，`saved_launch_argv`（493–520）与 runtime 创建（575–635）。cold 分支调用 shell 的 `spawn_with_initial_history`，不是普通 argv 重放；handoff 分支从 PTY FD 接管，并对有 saved argv 的 runtime 设置 `with_respawn_shell_on_exit()`。这是“冷恢复替换空壳”与“handoff 后退出可能变 shell”的依据。

<a id="h09"></a>
### H09 · Live handoff 丢失插件登记并重跑 hooks

[app/mod.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/app/mod.rs#L517)，初始 plugin_panes 为空；同文件 `new_from_handoff`（630–680）不恢复该表。[headless/bootstrap.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/server/headless/bootstrap.rs#L178)，handoff committed、assume ownership 后再次启动 hooks；普通启动在79附近也运行。

[plugins/mod.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/app/api/plugins/mod.rs#L525)，plugin pane focus/close 依赖该表（525–576）。本插件只能修复自己的 ownership 账本；stock API 没有重新登记旧 pane 为 plugin pane 的入口。后续操作需严格验证后用普通 pane API。

<a id="h10"></a>
### H10 · Pane 生命周期的进程清理

[pane.rs](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/pane.rs#L1435)，`Drop for PaneRuntime`；同文件 [shutdown_pane_processes](https://github.com/herdrdev/herdr/blob/b99002ac99b09e00b4ca692436cb15a6b0d676f1/src/pane.rs#L1493)：同 session 进程清理 HUP→250 ms→TERM→250 ms→KILL→250 ms。`preserve_for_handoff` / `assume_process_cleanup_ownership`（1825–1842）交接责任。SIGKILL 不执行 Rust Drop；Herdr 异常退出后的实际 PTY/HUP 传播必须运行 spike。

[run_startup.py](https://github.com/NousResearch/hermes-agent/blob/b7ac3ba1cdf89f94dfe86de27e01358b194f4053/gateway/run_startup.py#L1144)，startup zero-connections decision：全 nonretryable 可78，混合 transient/fatal 可保持 degraded，cron-only 可继续。PID/同 profile runtime lock 冲突在 [run.py](https://github.com/NousResearch/hermes-agent/blob/b7ac3ba1cdf89f94dfe86de27e01358b194f4053/gateway/run.py#L4981) 等分支可返回 False，最终1，并非全部78。

### M09 · Profile lifetime lock、PID、token lock

[gateway/status.py](https://github.com/NousResearch/hermes-agent/blob/b7ac3ba1cdf89f94dfe86de27e01358b194f4053/gateway/status.py#L157)，profile `gateway.pid/gateway.lock/gateway_state.json` 与共享 token lock root；`_get_process_start_time`（268–283）优先Linux `/proc` start ticks，读取／解析失败也会回退psutil create_time×100，其他POSIX通常走该fallback；`acquire_gateway_runtime_lock`（659–699）持有 flock；token lock（1038–1083）按凭据摘要 O_EXCL/stale cleanup。probe必须区分指纹来源，不能在fallback时混用单位。token lock 仅在同一个机器目录内共享，不自动覆盖跨主机、不同 UID 或不同 `HERMES_GATEWAY_LOCK_DIR`。不得为专用 profile 分配独立 token lock root 来绕过现有保护。
