# hermes on herdr identity

The public brand is **hermes on herdr**, with repository and command name `hermes-on-herdr`. The owner approved the brushed-brass frame, ajar petrol-blue enamel door, ivory terminal inlay and green status lens on September 11, 2026. The pale blue-gray presentation uses paired pane outlines and a returning route.

| File | Role |
| --- | --- |
| `../../logo.png` | Canonical transparent 2048 px master |
| `icon.png` | Square 2048 px presentation master |
| `icon-rounded.png` | Rounded 2048 px presentation used in both README headers |
| `source.json` | Original generation decision, selected pass, dimensions and checksums |

Use the transparent master for small application marks and the separate presentation for README or social artwork. The terminal dashboard uses its own Hermes caduceus character art; it does not render this bitmap logo. The project has no public web application or evidenced website palette.

The frame opening is transparent; the ivory prompt, brass reflections and green lens remain opaque. The object has at least 205.5 px clearance from the rounded outline. At 16 px, recognition comes from the brass frame and blue door; fine details merge.

The project was renamed on September 12, 2026. Original artwork bytes and checksums remain tied to study `hermes-gateway-herdr/2026-09-11-01`, finishing `01`. The historical archive name records the name used during generation. `source.json`, prompts, source decisions and export names retain that provenance. The earlier door emoji is preserved in Hexly as the original editorial profile identity.
